# Vible
바이블은 별도의 설치가 필요없는 미디어 서버입니다.
별도의 프로그램이 아닌 웹이기에 어느 웹브라우저든 접근 가능합니다.

사용 시 서버 PC에는 2가지가 선행되어야 합니다.

1. 파이썬 / 파이썬 패키지 설치가 필요합니다.(자동 설치 파일 제공)
2. 테일스케일 / 포트포워딩 없이 p2p방식으로 연결하기 위해 필요합니다.

사용방법
1. 파이썬을 설치합니다.(환경변수 패치 필수)
2. install_packages.bat 파일을 실행해 패키지를 설치합니다.
3. run.bat를 사용해 서버를 실행합니다.


참고사항
1. 바이브 코딩으로 제작되었습니다.
2. VibeVault는 알바버전 이름입니다.
3. 첫 폴더 스캔은 Vible이 저장된 위치에서 한 단계 위로 설정되어 있습니다.(기본 위치이며 내부에서 변경 가능)
  D:\스캔위치\Vible


재배포 및 판매를 엄격히 금지합니다.
